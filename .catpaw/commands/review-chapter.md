# /review-chapter

检查已有章节是否符合 writing-guide.md 的规则，给出具体修改建议。

## 参数

$ARGUMENTS = 章节编号（如 `4` 或 `04`）

## 执行步骤

1. 读取 `chapter-plan.json`，找到对应章节的配置
2. 读取 `writing-guide.md`，获取写作风格规则
3. 读取 `output_path` 中已有的章节内容
4. 逐条检查 writing-guide.md 中的规则：
   - 是否有反问句开场
   - 是否有感叹式过渡
   - 是否有逐段总结
   - 是否滥用加粗
   - 是否有 emoji
   - 是否有"小李"式拟人叙事
   - 代码引用是否标注了文件路径
   - 代码是否来自真实源码（抽查 1-2 段，与 claw-code 源码对比）
   - 是否有装饰性图片描述
   - 章节结构是否符合规范
5. 输出检查报告：
   - 列出每条违规项，标注位置和建议修改
   - 如果没有违规，明确说明"通过检查"
6. 询问用户是否需要自动修复，如果需要则执行 `/rewrite-chapter` 流程

## 注意

- 检查是只读操作，不修改文件
- 报告要具体到段落或行号，不要泛泛而谈
