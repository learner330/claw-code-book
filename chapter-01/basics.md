# 基础概念

本节介绍全书的基础概念，为后续章节打下基础。

## 核心术语

理解以下术语将帮助你更好地阅读后续内容：

**模块**：一个可复用的功能单元，可以独立开发和测试。

**组件**：UI 的基本构建块，负责渲染界面和处理用户交互。

**状态**：应用在某一时刻的数据快照，决定了界面的当前展示。

## 第一个示例

下面是一个简单的示例代码：

```javascript
function greet(name) {
  return `你好，${name}！`
}

console.log(greet('世界'))
```
